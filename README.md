# Generative AI Research Project

This repository organises materials for a research project exploring the use, benefits, risks, and responsible application of generative AI tools in academic or professional learning contexts.

The structure separates literature, qualitative data, quantitative data, reports, and supporting materials so that research files are easy to locate and maintain.

## Project Purpose

The project aims to investigate how people understand and use generative AI, with attention to:

- Common use cases for generative AI tools
- Perceived benefits for learning, research, and productivity
- Concerns about accuracy, ethics, privacy, and academic integrity
- Practical guidance for responsible and effective use

## Folder Guide

| Folder | Purpose |
| --- | --- |
| `Additional_Materials` | Supporting resources such as participant sheets, media records, and photo inventories. |
| `Drafts_and_Reports` | Working drafts, conference paper outlines, proposal notes, and final report materials. |
| `Literature_Review` | Books, journal articles, conference articles, and newspaper sources used to build the research background. |
| `Qualitative_Analysis` | Interview protocols, consent forms, transcript excerpts, codebooks, and thematic analysis outputs. |
| `Quantitative_Analysis` | Survey questions, raw data, processed data, analysis scripts, and quantitative reporting outputs. |

## Current Sample Contents

## Suggested Workflow

1. Store original survey exports in `Quantitative_Analysis/Raw_Data`.
2. Save cleaned datasets in `Quantitative_Analysis/Processed_Data`.
3. Keep interview recordings or notes separate from de-identified transcripts.
4. Place coding frameworks and theme summaries in `Qualitative_Analysis/Analysis`.
5. Draft written outputs in `Drafts_and_Reports` before moving final versions into `Final_Reports`.

## Notes

- Keep participant data de-identified where possible.
- Use clear file names with dates or version numbers for major drafts.
- Avoid storing sensitive personal information unless it is required and properly protected.
